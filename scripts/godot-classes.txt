# Which engine classes get bound methods and an L^ wrapper
# (scripts/gen-godot-api.py).
#
# One class per line; its whole inheritance chain comes along, so naming a
# leaf is enough.
#
# `under <Class>` takes every class under that one that Godot's own "create a
# new script" dialog would offer as a parent: the core API, able to be
# instantiated, exposed to scripting, and not blacklisted there. Together the
# lines below are the whole tree a script can be worn by, which is what the
# scene tree's dialog asks for (set_inheritance_base_type("Node")).
#
# ONE LINE IS ONE FILE. Each becomes demo/lhat/Godot/<name>.lh, and a class
# goes in the first line that reaches it -- so a narrow branch is named
# before a wide one and `under Node` at the end picks up the remainder. The
# split is not a choice about meaning: 03 の 5.2 gives a unit fewer than 250
# bindings and the tree is 251, so it has to live in more than one file.
# Nothing composes between wrappers, so where one lives changes nothing.
#
# What this list costs, measured. Checking is per class and grows with it: a
# base and a delegate are links rather than copies of a member list. Loading
# a unit is neither -- it is quadratic in how many methods are registered,
# whatever the unit holds. Loading the same .lh takes
#
#     366 methods    (6 classes)     66 ms
#   1,261 methods   (54 classes)  1,153 ms
#   5,566 methods  (251 classes) 18,728 ms
#
# and eb1a98a took the quadratic out: the same load is 75-122 ms now.

under Node2D
under Node3D
under Control
under Node

# The other tree. A script is worn by Resource itself -- a custom resource
# with @export fields, saved as a .tres and handed to a node through the
# inspector, which is how Godot spells data that is edited rather than
# written. What is under it is not worn but used: a Texture2D comes back from
# get_texture and a PackedScene is what instantiate is called on, and without
# them a script can pass such a thing around and do nothing with it. The line
# is the same one the editor's "new resource" dialog draws
# (filesystem_dock's set_base_type("Resource")).
#
# Three branches come off first, for the register limit above: the shader
# graph's nodes are a hundred classes on their own, and the textures and the
# audio effects are the next two crowds.
under VisualShaderNode
under Texture
under AudioEffect
under AnimationNode
under Mesh
under InputEvent
under AudioStream
under Material
under Resource

# What get_tree() answers. Not a Node and not a Resource -- a MainLoop -- but
# nothing a script does without: quitting, changing scene, a one-shot timer,
# the group calls. Its own subtree is three classes.
under SceneTree

# `singletons` takes every core singleton: a class the engine holds one
# instance of, which a script never has in hand. GDScript writes the class
# name and calls through it -- Input.is_action_pressed("ui_left") -- and so
# does L^, as functions of a module of their own:
#
#     godot.Input.is_action_pressed("ui_left")
#     godot.Time.get_ticks_msec()
#
# `singleton <Name>` takes one. Without these a script cannot read a key or
# ask the time, and nothing else reaches them: a singleton has no receiver
# for a member call to be written against.

singletons
