# Which engine classes get bound methods (scripts/gen-godot-api.py).
#
# One class per line; its whole inheritance chain comes along, so naming a
# leaf is enough.
#
# `under <Class>` takes every class under that one that Godot's own "create a
# new script" dialog would offer as a parent: the core API, able to be
# instantiated, exposed to scripting, and not blacklisted there.
#
# `singletons` takes every core singleton -- a class the engine holds one
# instance of, which a script never has in hand. GDScript writes the class
# name and calls through it, and so does L^, as functions of a module of
# their own:
#
#     godot.Input.is_action_pressed("ui_left")
#     godot.Time.get_ticks_msec()
#
# `singleton <Name>` takes one.
#
# `!<Class>` drops that class and everything under it. Whole branches rather
# than single classes, so what is left is always a tree: nothing can end up
# declared under something that is no longer there. Applied after every other
# line, so where a `!` is written does not matter.
#
# What this list costs is registration and the size of lhat-host.json, not
# checking: 05 の 8.8改 makes a base a link rather than a copy of a member
# list, so the checker's side is per class rather than per member. And it
# costs no L^ at all -- there is no wrapper library, since godot.Sprite2D is
# a type a script names directly.

# Everything a script can be worn by.
under Node
Resource

# What get_tree() answers: not a Node and not a Resource, but nothing a
# script does without.
under SceneTree

# What a script gets back and has to be able to use: a Texture2D off
# get_texture, a PackedScene to instantiate, an InputEvent in _input.
under Resource

# The rest of what a bound method hands back and the script then cannot use.
# Nothing here needs an ancestor that is not already in: RefCounted came
# along with Resource, and these hang off it or off Object.
#
# A tween is written as a chain -- create_tween().tween_property(...)
# .set_ease(...) -- so the Tweener a step answers with is as much a part of
# it as Tween itself.
Tween
Tweener
PropertyTweener
MethodTweener
CallbackTweener
IntervalTweener
SubtweenTweener
SceneTreeTimer

# What move_and_collide answers, and what _integrate_forces is handed.
KinematicCollision2D
KinematicCollision3D
PhysicsDirectBodyState2D
PhysicsDirectBodyState3D

# A Tree's rows, and a TileMapLayer's per-tile data.
TreeItem
TileData

# Raycasting. Held back until godot.Dictionary existed -- five of the six
# methods answer or take one, so binding the space state before that would
# have given a type nobody could write a query with.
#
# The parameters come too, and have to be named: they are RefCounted rather
# than Resource, so `under Resource` never reached them. A script makes one
# with godot.ClassDB.instantiate, which is how anything not a Node or a
# Resource is made from here.
PhysicsDirectSpaceState2D
PhysicsDirectSpaceState3D
PhysicsPointQueryParameters2D
PhysicsPointQueryParameters3D
PhysicsRayQueryParameters2D
PhysicsRayQueryParameters3D
PhysicsShapeQueryParameters2D
PhysicsShapeQueryParameters3D

singletons

# OpenXR reaches L^ half-way. These two are not instantiable and came in only
# as the ancestors of Resources `under Resource` reached, and what they are
# for -- OpenXRAPIExtension, OpenXRInterface -- is not here, so nothing can be
# done with what did arrive. Half a subsystem reads as a supported one, which
# is worse than none.
#
# The OpenXR *nodes* stay: OpenXRHand, OpenXRCompositionLayerQuad and the
# rest are what the editor offers as a script's parent, which is exactly what
# `under Node` is for.
