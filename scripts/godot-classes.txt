# Which engine classes get bound methods (scripts/gen-godot-api.py).
#
# One class per line; its whole inheritance chain comes along, so naming a
# leaf is enough.
#
# `under <Class>` takes every class under that one that the engine can make:
# the core API, able to be instantiated, and not one of the two names Godot's
# own "create a new script" dialog blacklists. `under Object` is therefore
# everything -- which is what this list wants, since a class a script can be
# handed is a class a script should be able to use.
#
# `singletons` takes every core singleton -- a class the engine holds one
# instance of, which a script never has in hand. GDScript writes the class
# name and calls through it, and so does L^, as functions of a module of
# their own:
#
#     godot.Input.is_action_pressed("ui_left")
#     godot.Time.get_ticks_msec()
#
# `singleton <Name>` takes one.
#
# `!<Class>` drops that class and everything under it. Whole branches rather
# than single classes, so what is left is always a tree: nothing can end up
# declared under something that is no longer there. Applied after every other
# line, so where a `!` is written does not matter. Nothing uses it now; it is
# here for a branch that turns out to cost more than it is worth.
#
# What this list costs is registration and the size of lhat-host.json, not
# checking: 05 の 8.8改 makes a base a link rather than a copy of a member
# list, so the checker's side is per class rather than per member. And it
# costs no L^ at all -- there is no wrapper library, since godot.Sprite2D is
# a type a script names directly.

# Everything the engine can make, and every ancestor of one. 859 classes.
under Object

# 05 の 8.7: the ones the engine holds a single instance of, which become
# functions of a module of their own rather than a type.
singletons

# What is left over: a class the engine never instantiates and nothing
# instantiable inherits from, so no `under` reaches it -- yet a bound method
# hands one to a script. Each has to be named.
#
# A file, a directory, a row of a Tree, a tile's data, the timer create_timer
# answers, the state a PackedScene keeps, a playback an AudioStreamPlayer
# hands out, the device a compute shader runs on.
DirAccess
FileAccess
TreeItem
TileData
SceneTreeTimer
SceneState
SkinReference
RenderingDevice
TLSOptions
ENetPacketPeer
InstancePlaceholder
PackedDataContainerRef
AudioEffectSpectrumAnalyzerInstance
AudioStreamGeneratorPlayback
AudioStreamPlaybackInteractive
AudioStreamPlaybackPolyphonic
OpenXRFutureResult
WebXRInterface

# The same, and with no callable method of their own -- so what naming them
# buys is the type itself: a value crosses as what it is rather than as the
# nearest ancestor that was registered.
Node3DGizmo
JavaScriptObject
ResourceImporter
AudioStreamPlaybackPlaylist
AudioStreamPlaybackSynchronized

# The one editor-API class named here. A script is worn by it the way a
# resource is worn -- the import dock's Custom Script field -- and what it
# does is take the imported scene apart and put it back together, which is
# every Node method and no editor one. It drags nothing in: RefCounted and
# Object are already here, get_source_file answers a string, and _post_import
# is a virtual, which is implemented rather than called.
#
# In an exported game the class does not exist, so its one method's bind is
# NULL and calling it would fault -- which nothing does, since nothing
# imports a scene at run time.
EditorScenePostImport

# MissingNode and MissingResource are left out, as Godot leaves them out of
# its own dialog: each stands for a class a scene named and the build does
# not have, so what a script would do with one is nothing.

# Nothing can hand a script one of these and nothing can make one. weakref()
# is the only maker and it is a utility function; ClassDB.instantiate answers
# one that is permanently empty, since set_ref is not exposed. Nor would it
# earn its place if it were reachable: a godot.Object holds an instance id
# rather than a pointer, so it is ALREADY weak for everything that is not
# reference counted, and isValid() is the question WeakRef would answer.
#
# Counted over Godot's own 690 .gd files: weakref( appears zero times, and
# the two mentions of the type are both in the GDScript test suite, testing
# WeakRef rather than using it.
!WeakRef
